# 🌙Luna AI🌙 #

Персональный проект AI-асистента. 

Я его создал на базе LLM и интегрировал в его Silero (В будущем GPT-SoVist), который переводит текст в реч, Whisper (раньше vosk), который отвечает за перевод речи в текст. В ближайшее время планирую сделать графику через какое нибуть приложение например VTubeStudio. Идея заключается в том, что я будучи не самым крутым програмистом, должен написать полноценный проект который будет работать автономно, без использования внешних серверов, тоесть все должно работать локально.

## 🛠 Мой ПК ##
- **GPU**: NVIDIA GeForce RTX 5070 (12GB VRAM)
- **CPU**: AMD Ryzen 7 7000
- **RAM**: 32GB DDR5
- **DRIVE**: 1 TB SSD m2 + 1 TB HDD
- **OS**: Win 11

Для работы требуется отдельная программа - [`Ollama`](https://ollama.com/). 

## Файлы проекта, их назначение в проекте.
- **AIVoce.py**, отвечает за озвучку ответа, в целом это единственный смысл существования этого файла, без его основной маин будет работать, но ответы будут онли текстом.
- **VoceCon.py**, отвечает за извлечение текста из речи через Whisper
- **main.py**, отвечает за связку в целом всего проекта. Все файлы идут через его, запускаем тоже его, вообщем файл - пульт управления
- **requirements.txt**, тут лежат все библеотеки на момент разработки, позже я почищу его от ненужных
- **start.bat**, запускает Ollama, основной скрипт. Создает папку .venv, устанавливает библиотки. (настроен на torch cu128, если нужно ниже - перенастройте)
- **system_promt.txt**, нужен для хранения системных инструкций для нейросети, повзволяет задать ей личность, или настроить правила общения.
- **Log.txt**, хранит данные переписки. Нужне только что бы смотреть переписку с ассистентом, дает возможность понять на каком моменте происходит сбой личности\иные проблемы связанные не с программой.
